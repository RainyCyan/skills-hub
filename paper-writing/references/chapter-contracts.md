# 章节契约

在设计目录、重构章节或起草特定章节时加载本文件。学校模板优先于以下默认结构；学科惯例与研究设计可以改变章节名称，但不能取消论证职责。

## 目录设计

目录不是材料分类表，而是总论证链的分段。每章先写一句“本章使读者接受什么”，再决定标题与小节。

检查相邻章节：

- 后一章是否使用了前一章的明确输出。
- 同一概念、方法或结果是否在多章重复介绍。
- 理论、方法、结果和讨论是否因学科惯例需要合并，而不是机械拆分。
- 标题是否只表达一个中心问题，是否避免多个名词用“与、及”拼接。
- 删除该章后总论证链是否真的断裂；不影响则合并或删除。

## 摘要

**输入**：论文定稿后的研究问题、方法、主要结果和边界。

**必须回答**：

1. 在什么对象和场景下存在什么具体问题。
2. 本文提出了什么研究问题或目标。
3. 使用了什么数据、材料、方法或系统设计。
4. 得到哪些带口径的关键结果。
5. 结果在什么边界内意味着什么。

**禁止**：

- 在正文未完成前虚构结果型摘要。
- 只有背景和意义，没有方法与数字。
- 引入正文未定义或未使用的贡献。
- 用“具有重要意义”代替结论。

摘要必须最后定稿，且其中所有数字可在正文中定位。

## 绪论

**输入**：现实或理论问题、初步文献地图、研究设计。

**输出**：读者理解本文为什么需要做、具体问什么、准备如何回答。

建议顺序：

1. 从可证实的问题和边界进入，不从宏大时代背景进入。
2. 说明已有研究已经解决什么。
3. 定位尚未解决的限制，并给出文献证据。
4. 提出研究问题、假设或目标。
5. 概述研究设计、贡献和全文结构。

“创新点”必须写成可核验差异：新对象、新数据、新约束、新方法、新证据或新解释。不能把“首次、系统、全面”当作创新。

## 文献综述与理论基础

**输入**：明确研究问题、检索范围和已核验文献。

**输出**：概念边界、路线分歧、证据状态和本文切入点。

每节按同一分析维度比较文献，例如问题定义、理论机制、方法路线、数据条件、结论差异或适用边界。段落应完成“综合”而非“逐篇摘要”。

理论基础只保留后文实际用于提出假设、设计方法或解释结果的理论。没有进入后续推理的教材式介绍应删除或压缩。

## 研究问题与假设

研究问题必须能由后续材料回答。假设应明确变量、方向、条件和分析单位。

不要在看到结果后把观察改写成事前假设。探索性发现应标为探索性结果。

每个问题或假设建立以下映射：

`研究问题/假设 -> 操作化定义 -> 数据或材料 -> 分析方法 -> 判定标准 -> 结果位置`

映射中存在空项时，不进入结论写作。

## 方法、系统或模型

**输入**：研究问题、约束、数据或材料条件。

**输出**：足以复现和判断方法适用性的研究设计。

应交代：

- 研究对象、数据来源、样本和纳入排除规则。
- 变量、概念、材料或任务的操作化定义。
- 流程、模型、系统模块或分析步骤。
- 参数选择、对照方案、评价指标和停止条件。
- 伦理、隐私、偏差和有效性威胁。
- 选择该方法的理由与替代方案。

公式按“对象定义 -> 假设条件 -> 推导 -> 结果 -> 解释”出现。公式前说明为什么需要它，公式后只解释新变量及其作用，不用自然语言复述整式。

## 结果

**输入**：真实分析或实验输出及预先定义的指标。

**输出**：与研究问题一一对应、尚未过度解释的观察结果。

按研究问题或假设组织，不按生成文件或运行顺序组织。每个结果单元包含：

1. 条件、样本和指标。
2. 可定位的表、图或统计结果。
3. 与基线或预期的比较。
4. 必要的不确定性、异常和负结果。

结果章主要回答“观察到什么”。机制解释、与文献的冲突和外推含义放入讨论，除非本学科惯例要求合并“结果与讨论”。

## 讨论

**输入**：结果、理论预期、相关研究和有效性边界。

**输出**：对结果的解释、替代解释、贡献、限制与外部含义。

按以下推理顺序组织：

1. 回答研究问题，不逐表复述结果。
2. 解释结果为何出现，并说明解释依赖的假设。
3. 与支持和冲突的文献比较。
4. 检查替代解释与有效性威胁。
5. 区分理论贡献、方法贡献和实践含义。
6. 缩小到证据允许的适用边界。

限制必须具体到影响方向，例如“样本来自单一机构，因此无法判断跨机构泛化”，不能只写“样本量有限”后立即宣称不影响结论。

## 结论与展望

**输入**：已经过证据审计的研究问题、结果、贡献和限制。

**输出**：对全文问题的最终回答及下一步可执行研究。

结论不引入新数据、新文献或新方法。每个结论都能回指正文中的证据。

展望由已识别限制推出，写清对象、需要新增的证据和可验证目标。不要使用“未来将进一步深入研究”这类无对象承诺。

## 图、表、公式和附录

- 图表必须回答正文中的具体问题，不能只为丰富版面。
- 标题说明对象、条件和指标；单位、样本量和缩写在图表内或注释中可理解。
- 正文不逐格复述表格，应指出比较关系、异常和与论点相关的数值。
- 同一数据不无理由同时用图和表重复展示。
- 附录放置复现所需但会中断主论证的材料；正文必须引用附录。

## 章内闭环

每章交付前验证：

1. 章首提出的问题是否在章末得到回答。
2. 核心主张是否各有证据。
3. 图表、公式和引用是否参与论证，而非孤立陈列。
4. 本章输出是否为下一章实际使用。
5. 章末是否只总结已证明内容，没有新增主张。
